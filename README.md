# Shooter

Bright Fury is a working game systems tech demo developed in Unreal Engine C++ to showcase foundational gameplay mechanics and system integration. It includes core features such as:

-Custom Locomotion System
-Modular AI Behavior and Combat
-Weapon & Ammo Systems
-Pickup, Throw, and Interact Mechanics
-Fully functional Sound System

This project was built as a learning experience, helping me gain deep knowledge in C++ gameplay architecture, datatables, materials and shaders, and game system depth. Though the current footage shows a test level, all core systems are functional and ready for gameplay expansion.
